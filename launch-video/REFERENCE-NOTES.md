## Typography

Heavy geometric sans, single-storey `g`, tight tracking — Poppins/Gilroy family.
I won't claim an exact ID from 720p, and it doesn't matter:

**Cabinet Grotesk Extrabold** (fontshare.com, free commercial) sits in the same
category and is warmer, which suits cream better than Poppins' colder circles.
**Satoshi** for body. Both download as OTF and install for AE.

## Pacing

- Statement cards hold ~2.5–3.5s
- Product shots run 4–7s with continuous slow movement
- Cuts land on the music, never mid-motion
- Roughly 55% product / 45% typography

## What it does that we shouldn't copy

- **No proof shot.** It shows the UI but never shows an action completing.
  Auren's confirmation → execution → result sequence is a genuinely stronger beat.
- **Price card mid-film** ("Pay $60") kills momentum. Ours ends on the product.
- Purple neon is the default AI-product look. Cream + orange is not — lean into it.
